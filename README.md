# Playground Archive & Demos

Consolidated monorepo containing public experiments, live web applications, 1-shot procedural game engines, and utilities with full original commit histories preserved in dedicated subdirectories.

## 🎮 Live Demos
- **[СвітлоКарта України (SvitloMap)](https://svitlo.zeltanews.com)** — 60 FPS Canvas night-sky simulation of 25,897 settlements across Ukraine. Integrates 24-hour blackout schedules, live telemetry from 2,700+ SvitloBot IoT pingers via Cloudflare Edge Cache (`s-maxage=120`), and dynamic zero-queue regional detection. ([Cloudflare Pages Mirror](https://svitlo-map.pages.dev) &bull; [Source](svitlo-map/)).
- **[Play Atari Breakout (1976 Arcade 1-Shot)](https://babych.github.io/playground/breakout/)** — Authentic 1976 arcade machine with CRT scanlines, continuous sub-stepping physics, paddle shrinking on red wall breach, and procedural 8-bit audio.
- **[Play Super Mario Bros. (Gemini Argon 1-Shot)](https://babych.github.io/playground/super-mario/)** — Complete World 1-1 written from scratch in one single hit by Gemini Argon (Pure HTML5 Canvas + Web Audio API).

## Included Projects
- **svitlo-map** - Real-time blackout map and power grid simulator (HTML5 Canvas, Cloudflare Pages, SvitloBot API edge caching)
- **breakout** - Atari Breakout 1976 arcade 1-shot procedural engine (Canvas + Web Audio)
- **super-mario** - Gemini Argon 1-shot Super Mario NES engine (Canvas + Web Audio)
- **headcases** - Diagnostic/test cases
- **bee-book** - Ukrainian translation of A.I. Root's ABC and XYZ of Bee Culture (Typst / assets)
- **PascalCompilerPy** - Pascal compiler written in Python
- **FlaskPortalPy** - Python Flask portal project
- **PrimesAot** - Prime numbers generation with .NET AOT
- **BasicKubePy** - Basic Python API deployment into Kubernetes
- **BasicKube** - Simple .NET API with MediatR and deployment into Kubernetes
- **wireguard-azure-github-actions** - Automation for WireGuard deployment via Azure and GitHub Actions
- **DurablePerfTest.AzF** - Azure Functions Durable performance test harness
- **AdoDataMapper** - Lightweight ADO.NET DataMapper library
- **html5_jo_sample** - Historical HTML5 mobile framework sample (2013)
