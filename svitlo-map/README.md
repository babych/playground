# СвітлоКарта України (SvitloMap)

Нічна супутникова карта енергосистеми України з 25 800+ населеними пунктами (міста, смт, села). Показує реальний стан електропостачання та графіки погодинних відключень (ГПВ) у режимі 24-годинної симуляції.

👉 **Демо**: [https://svitlo-map.pages.dev](https://svitlo-map.pages.dev)

---

## Як це працює

### 1. Рендеринг 25 800+ точок без лагів
- Замість важких DOM-елементів або SVG-маркерів Leaflet, усі 25 897 точок малюються через один прозорий шар HTML5 Canvas.
- Використовується просторове відсікання (**Frustum Culling**): на кожному кадрі розраховуються і малюються тільки ті точки, які потрапляють у поточний екран карти + невеликий буфер (`south/north/west/east`).
- Сяйво працює через `ctx.globalCompositeOperation = 'screen'` (адитивне змішування), що створює реалістичний ефект світлового купола нічного міста та сузір'їв сіл.

### 2. Графіки відключень та динамічний режим «0 черг»
- **Прив'язка черг (1..6)**: кожне село та місто прив'язані до секторальних черг обленерго за географічними координатами та районами.
- **24-годинна шкала**: інтерактивний слайдер від 00:00 до 23:00 розраховує статус кожної точки за графіком доби.
- **Динамічне виявлення «0 черг»**:
  - У багатьох регіонах (Карпати, Закарпаття, Буковина, Одеса тощо) НЕК «Укренерго» часто застосовує режим 0 черг (світло не вимикають).
  - Алгоритм аналізує кластери живої телеметрії СвітлоБота (~35 км). Якщо в секторі >88% датчиків онлайн або немає зафіксованих вимкнень, карта автоматично знімає відключення та підсвічує точки золотим світлом замість малювання сліпих графіків.

### 3. Edge-кешування телеметрії (Cloudflare Pages Function)
- Браузери клієнтів не стукають напряму в `svitlobot.in.ua`, щоб не перевантажувати їхній сервер.
- Запит іде на проксі `/api/svitlobot` (`functions/api/svitlobot.js`), який кешує відповідь на крайових вузлах Cloudflare Edge на 120 секунд (`Cache-Control: public, s-maxage=120`).
- Навіть при десятках тисяч відвідувачів навантаження на першоджерело становить не більше 1 запиту на 2 хвилини.

## Структура репозиторію

```
svitlo-map/
├── index.html                  # Головний інтерфейс (HUD, таймлайн, картка населеного пункту)
├── styles.css                  # Glassmorphism стилі, адаптив під мобільні
├── app.js                      # Canvas-рушій, логіка Frustum Culling, розрахунок черг і телеметрії
├── _headers                    # Правила кешування для Cloudflare Pages
├── functions/
│   └── api/
│       └── svitlobot.js        # Cloudflare Pages Function (Edge Cache проксі на 120 сек)
└── data/
    ├── settlements_25k.json    # База 25 897 сіл і міст [lat, lon, name, category, group]
    ├── hromadas_points.json    # Точки 1 315 територіальних громад
    ├── hromadas_boundaries.geojson # Векторні контури меж громад
    └── ukraine_full.geojson    # Державні кордони України для фону
```

## Локальний запуск

Проєкт повністю статичний, збірка не потрібна.

```bash
# Клонувати репозиторій
git clone https://github.com/babych/playground.git
cd playground/svitlo-map

# Запустити будь-який локальний HTTP-сервер
python -m http.server 8080
# або
npx serve .
```

Відкрити у браузері `http://localhost:8080`.

Для локального тестування Cloudflare Pages Functions з кешем:
```bash
npx wrangler pages dev .
```
